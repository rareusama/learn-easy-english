How to Use Can and Could in English with Urdu

Learn how to use can and could for ability, permission and polite requests.

This beginner-friendly lesson explains the topic step by step. Read each example, notice the pattern, and then make your own sentences. Learning a little every day is more effective than trying to memorise everything at once.

اردو میں: ہر مثال کو غور سے پڑھیں، اس کا مطلب سمجھیں اور پھر اپنی طرف سے ایک نیا جملہ بنائیں۔

Using “can” for ability

Can describes something a person is able to do now or generally.

I can swim.
میں تیر سکتا ہوں۔
She can speak English.
وہ انگریزی بول سکتی ہے۔

Using “can” for permission and requests

Can I use your phone?
کیا میں آپ کا فون استعمال کر سکتا ہوں؟
Can you help me?
کیا آپ میری مدد کر سکتے ہیں؟

Using “could”

Could can describe past ability, and it is also commonly used to make a request sound more polite.

When I was young, I could run fast.
جب میں چھوٹا تھا تو تیز دوڑ سکتا تھا۔
Could you open the window, please?
کیا آپ براہِ کرم کھڑکی کھول سکتے ہیں؟

Sentence structure

Use can or could + the base form of the verb. Do not add “s” after can: say “He can play,” not “He can plays.” For negatives, use cannot/can't or could not/couldn't.

Quick practice

Complete: “My sister ___ cook very well.” If she has this ability, use “can.” For a polite request, try: “Could you repeat that, please?”

Practice task: Write five original sentences using the rules in this lesson. Read them aloud, then check your spelling and grammar.

This lesson is for English-learning practice. Meanings can vary slightly with context.

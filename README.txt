# Learn Easy English — starter website

This is a responsive, bilingual English-learning website starter.

## Files
- `index.html` — homepage
- `articles.html` — lesson directory
- `articles/` — five starter lessons
- `about.html`, `contact.html`, `privacy-policy.html`, `disclaimer.html`
- `assets/style.css` — responsive styling

## Before publishing
1. Replace the placeholder email instruction on `contact.html` with an email address you control.
2. Review all pages and add your own accurate details.
3. Add more genuinely useful, original lessons. Five starter articles are not a guarantee of AdSense approval.
4. Add a real custom domain if/when your budget allows. Free subdomains may be less suitable for long-term branding.
5. Set up a hosting provider and connect the site.
6. Add Google Search Console after publishing and submit the sitemap if you create one.
7. Apply to AdSense only when the site has substantial original value, clear navigation, working pages and complies with current policies.
8. If you add analytics, cookies, contact forms or ads, update the privacy policy and consent setup as required.

## Publish free (static hosting)
You can publish these files using GitHub Pages:
1. Create/sign in to a GitHub account.
2. Create a new public repository, for example `learn-easy-english`.
3. Upload the contents of this folder (not the ZIP file itself) to the repository root.
4. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`, then save.
5. GitHub will provide a public website URL after deployment.

The exact GitHub interface may change. A free GitHub Pages URL is a starting point; a custom domain generally costs money.

## Important
This is a static website. It does not include a backend, database, user accounts, newsletter or working contact form. The contact page asks you to publish a real email address. This starter package does not include an AdSense account, guarantee approval, or place ad code.
